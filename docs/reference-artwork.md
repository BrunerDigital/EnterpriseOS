# Digital360 reference artwork

The three images supplied for the BrunerDigital and Digital360 design refresh are served as local WebP assets under `public/brand/artwork/`. They are decorative backgrounds; the original Digital360 logo remains the brand mark.

| Source | Asset | Placement |
| --- | --- | --- |
| Photo 1 | `signal-orb.webp` | Product homepage and shared sign-in and password recovery frame |
| Photo 2 | `wireframe-horizon.webp` | Shared public interior backdrop and subtle workspace canvas |
| Photo 3 | `particle-wave.webp` | Homepage walkthrough, shared calls to action and footer, dashboard and module banners, and onboarding |

`app/artwork.css` holds the crops, text overlays, navigation colors, and high contrast fallback. Keep artwork static and out of data surfaces. Use the shared workspace banner and toolbar styles when new modules need the same treatment.
